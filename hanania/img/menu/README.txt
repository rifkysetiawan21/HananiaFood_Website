### Folder Foto Menu

Folder foto menu merupakan tempat penyimpanan gambar yang digunakan untuk menampilkan setiap produk makanan dan minuman pada halaman katalog website Hanania Food. Setiap gambar memiliki nama file yang disesuaikan dengan nama menu agar dapat dikenali dan ditampilkan oleh sistem.

Foto menu menggunakan format `.jpg` dengan rasio gambar 4:3, misalnya 800 × 600 piksel. Ukuran setiap file disarankan tidak lebih dari 200 KB agar proses pemuatan gambar pada website tetap ringan.

Berikut merupakan daftar nama file foto yang digunakan pada menu:

| Nama File - Nama Menu |
| `nasi-box-ayam-bakar.jpg` - Nasi Box Ayam Bakar |
| `nasi-kuning-komplit.jpg` - Nasi Kuning Komplit |
| `risoles-ragout.jpg` - Risoles Ragout |
| `es-teh-manis.jpg` - Es Teh Manis |
| `paket-rapat.jpg` - Paket Rapat |
| `ikan-bakar.jpg` - Ikan Bakar |

Penamaan foto untuk menu baru mengikuti nama menu yang telah diubah menjadi huruf kecil, dengan setiap spasi diganti menggunakan tanda hubung (`-`). Sebagai contoh, menu "Soto Ayam" menggunakan nama file `soto-ayam.jpg`. Ketentuan ini menjaga kesesuaian antara data menu dan file gambar yang digunakan.

### Foto Hero (Beranda)

Foto hero merupakan gambar utama yang ditampilkan pada bagian awal halaman beranda website Hanania Food. Gambar ini berfungsi sebagai elemen visual yang memperkenalkan layanan catering sekaligus memberikan tampilan awal yang menarik bagi pengunjung website.

File foto hero menggunakan nama `hero-catering.jpg` dan disimpan langsung di dalam folder `img/`, terpisah dari folder foto menu. Format yang digunakan adalah `.jpg` dengan rasio gambar 16:9, misalnya 1600 × 900 piksel. Ukuran file disarankan tidak lebih dari 300 KB.

Gambar dengan orientasi horizontal lebih sesuai untuk area hero karena dapat mengisi tampilan layar dengan lebih proporsional. Sementara itu, gambar dengan orientasi vertikal tetap dapat digunakan, tetapi sebagian area gambar berpotensi terpotong menyesuaikan ukuran tampilan.

Apabila file foto hero belum tersedia, bagian beranda tetap dapat ditampilkan menggunakan latar belakang berwarna terang dan teks tanpa gambar.

FOLDER FOTO MENU
Taruh foto menu di folder ini. Nama file harus SAMA PERSIS dengan daftar di bawah.
Format .jpg, rasio 4:3 (contoh 800x600 px), ukuran sebaiknya di bawah 200 KB.

  nasi-box-ayam-bakar.jpg    -> Nasi Box Ayam Bakar
  nasi-kuning-komplit.jpg    -> Nasi Kuning Komplit
  risoles-ragout.jpg         -> Risoles Ragout
  es-teh-manis.jpg           -> Es Teh Manis
  paket-rapat.jpg            -> Paket Rapat
  ikan-bakar.jpg             -> Ikan Bakar (menu tambahan dari admin)

Menu baru yang ditambah admin: nama file = nama menu huruf kecil, spasi diganti "-".
Contoh: "Soto Ayam" -> soto-ayam.jpg
